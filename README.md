Python Fundamentals 🐍

A structured Python learning repository demonstrating core programming concepts through practical examples. 
This project covers essential Python fundamentals, helping learners develop a strong foundation in programming.

📚 Topics Covered

1. Variables and Data Types

File: variables_datatypes.py

Variables and variable assignment

Basic data types: String, Integer, Float, and Boolean

Collection data types: List, Tuple, Set, and Dictionary

Checking data types using type()

2. Conditional Statements

File: conditions.py

if, elif, and else statements

User input and input validation

Exception handling for invalid numeric input

Grade calculation based on marks

3. Data Structures

File: data_structures.py

Lists: Ordered and mutable collections

Tuples: Ordered and immutable collections

Sets: Collections of unique values

Dictionaries: Key-value pairs

Accessing, updating, and iterating through data

4. Loops and Patterns

File: loops.py

for loops and while loops

Printing numbers from 1 to 10

Displaying even numbers from 1 to 50

Calculating the sum of natural numbers

Generating star patterns

Creating multiplication tables

5. Functions

File: functions.py

Defining and calling functions

Function arguments and return values

Creating a greeting function

Checking whether a number is prime

Calculating the factorial of a number

6. File Handling

File: file_handling.py

Creating and writing text files

Reading file contents

Searching for words within a file

Appending content to existing files

Using Python's pathlib module

7. Object-Oriented Programming (OOP)

File: oops.py

Creating classes and objects

Using the __init__() constructor

Understanding attributes and methods

Calculating students' average marks

Displaying student information
